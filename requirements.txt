# 파이프라인 실행에 필요한 파이썬 패키지 — 버전 고정본
#
# 왜 고정하는가(S7 보안감사 H-1, 공급망 하드닝):
#   지금 워크플로는 `pip install requests pandas` 처럼 버전 없이 설치한다.
#   그러면 어느 날 상위 버전이 나오는 순간 아무도 손대지 않은 파이프라인의
#   동작이 바뀔 수 있고, 문제가 생겨도 "어제와 뭐가 달라졌는지"를 되짚을 수
#   없다. 실제로 앱 쪽에서 share_plus 13.3.0이 컴파일조차 되지 않는 일을
#   겪었다(2026-08-22) — 버전을 고정해 두지 않으면 그런 변화가 예고 없이 들어온다.
#
# ⚠ 이 파일은 아직 워크플로가 참조하지 않는다.
#   워크플로 파일을 고치려면 GitHub 토큰에 workflow 스코프가 필요한데 아직
#   없다(MT-001). 스코프가 부여되면 두 워크플로의 `pip install ...` 줄을
#   `pip install -r requirements.txt` 로 바꾸고, **바꾼 뒤 첫 실행을 반드시
#   확인할 것.** 아래 "검증 상태"에서 미검증으로 표시된 것들이 그때 처음
#   실환경에서 돌아간다.
#
# 갱신 방법:
#   버전을 올릴 때는 한 번에 하나씩 올리고, 올린 뒤 workflow_dispatch 로
#   해당 워크플로를 수동 1회 실행해 성공을 확인한 다음 커밋한다.
